  <p><strong>Course Type:</strong> Major Course (MJC)</p>
  <p><strong>Semester:</strong> Spring 2026</p>
  <p><strong>Teaching Hours:</strong> 0:1:4 (Lecture:Tutorial:Practical)</p>
  <p><strong>Credits:</strong> 3</p>
  <p style="text-align:justify;">
    This course introduces students to backend web application development using <strong>ASP.NET Core</strong> (latest LTS version).  
    It focuses on building scalable, secure, and maintainable web applications through the <strong>MVC pattern</strong>,  
    middleware configuration, <strong>dependency injection</strong>, and RESTful API development.
  </p>
</div>

<!-- ================== Course Outcomes ================== -->
<div style="background:#f8f9fa; border-radius:10px; border-left:5px solid #007BFF; padding:20px; margin-bottom:30px;">
  <h3>Course Outcomes (CO)</h3>
  <ul>
    <li><strong>CO1:</strong> Design, develop, and deploy dynamic web applications using ASP.NET Core and Razor syntax.</li>
    <li><strong>CO2:</strong> Configure and use middleware, routing, and dependency injection for maintainable applications.</li>
    <li><strong>CO3:</strong> Implement secure authentication and authorization techniques in ASP.NET Core.</li>
    <li><strong>CO4:</strong> Develop and document RESTful Web APIs using Swagger and consume external APIs via Postman.</li>
    <li><strong>CO5:</strong> Utilize logging, exception handling, unit testing, and custom middleware to ensure reliability.</li>
  </ul>
</div>
