<!-- ================== Course Objectives ================== -->
<div style="background:#f8f9fa; border-radius:10px; border-left:5px solid #007BFF; padding:20px; margin-bottom:30px;">
  <h3>Course Objectives</h3>
  <ul>
    <li>Understand the principles and practices of DevOps and Cloud-Native development.</li>
    <li>Implement automated CI/CD pipelines for code integration and deployment.</li>
    <li>Use containerization and orchestration tools such as Docker and Kubernetes.</li>
    <li>Configure monitoring, logging, and alerting in cloud environments.</li>
    <li>Learn Infrastructure as Code (IaC) with tools like Terraform or AWS CloudFormation.</li>
  </ul>
</div>
